# 🎯 Quiz Interativo: Profissão do Futuro

Este é um projeto educacional de teste vocacional desenvolvido com **HTML**, **CSS** e **JavaScript**, que visa ajudar estudantes a descobrirem qual área profissional mais combina com seu perfil: **Tecnologia**, **Saúde** ou **Gestão**.

## 💡 Objetivo

Propor um quiz interativo simples e intuitivo que, com base nas respostas do usuário, sugere áreas de atuação e cursos compatíveis com seus interesses e habilidades.

## 🧱 Tecnologias Utilizadas

- HTML5
- CSS3 (com responsividade e efeitos visuais)
- JavaScript (lógica do quiz, pontuação e resultado)
