# 🎯 Quiz Interativo: Profissão do Futuro

Este é um projeto educacional de teste vocacional desenvolvido com **HTML**, **CSS** e **JavaScript**, que visa ajudar estudantes a descobrirem qual área profissional mais combina com seu perfil: **Tecnologia**, **Saúde** ou **Gestão**.
---

## 💡 Objetivo

Propor um quiz interativo simples e intuitivo que, com base nas respostas do usuário, sugere áreas de atuação e cursos compatíveis com seus interesses e habilidades.
---

## 🧱 Tecnologias Utilizadas

- HTML5
- CSS3 (com responsividade e efeitos visuais)
- JavaScript (lógica do quiz, pontuação e resultado)
---

## 📦 Estrutura de Arquivos

# 📁 projeto-quiz-profissao/
├── index.html # Estrutura da página
├── style.css # Estilização visual
└── script.js # Lógica do quiz
---

## 🚀 Como Usar

1. **Clone ou baixe** este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Clique em “Começar” e responda às perguntas.
4. Veja a sugestão de área e cursos recomendados ao final.
---

## 🧠 Funcionamento

- O quiz contém 9 perguntas, cada uma com 3 alternativas (A, B, C).
- Cada alternativa está associada a uma área:
  - **A** → Tecnologia
  - **B** → Saúde
  - **C** → Gestão
- Ao final, a área com maior número de respostas é apresentada com cursos e detalhes extras (faculdades e técnicos).
---

## ✨ Funcionalidades Extras
